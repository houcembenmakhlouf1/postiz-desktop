Postiz Desktop

Privacy Policy

Last updated 27 October 2026. Applies to the private "Postiz Desktop" application registered by its owner for personal use.

What this application is

Postiz Desktop is a personal installation of the open-source Postiz scheduling software, running on one computer that belongs to the application owner. It is used only to schedule and publish the owner's own posts to the owner's own social media accounts. It is not offered to the public and has no other users.

Data we access

When the owner connects a social media account, the application receives an access token and basic profile information (account name, profile picture, account id) from that platform. It uses them only to publish the posts the owner creates and to show the account inside the application.

Where data is stored

All data, including access tokens, drafts, scheduled posts and uploaded media, is stored in a database on the owner's own computer. Nothing is sent to any server operated by the application owner or by third parties, other than the social media platforms themselves when a post is published.

Sharing

No data is sold, shared or transferred to anyone. The only recipients of content are the social media platforms chosen by the owner, and only when the owner publishes to them.

Deletion

The owner can disconnect an account inside the application at any time, which deletes its token, or revoke access from the platform's own settings. Removing the application's data folder deletes all stored data permanently.

Contact

Questions about this policy can be addressed to the application owner at the contact email registered with the platform's developer account.
